🔄 Pipeline Flow

1

Site Discovery

  • list_sharepoint_sites.py fetches all sites via Graph API
  • comparison.py diffs against sharepoint_sites.json
  • Outputs added_sites array (new sites only)
2

Document Extraction

  • Recursive folder traversal via GraphClient
  • Path pattern matching → department + document_type
  • Extracts metadata: name, URL, path, modified date, version
3

Classification & Export

  • TRACKS mapping: folder → department
  • DOCUMENT_PATHS patterns: path → Neo4j label
  • Outputs per-site JSON + folder tree visualization
4

Neo4j Ingestion

  • main.py orchestrates full pipeline
  • ingest_to_neo4j.py generates Cypher
  • MERGE on sharepoint_url = upsert
  • Dual labels: Document:TYPE

🔧 Extending the Pipeline

Add New Document Type

  1. Add to VALID_DOC_TYPES in ingest_to_neo4j.py
  2. Add path pattern to DOCUMENT_PATHS in sharepoint_new_site_pipeline.py
  3. Neo4j label created automatically via MERGE

Add New Track

  1. Add to TRACKS mapping in pipeline
  2. Add to EXISTING_TRACKS in ingestion
  3. Add to DEPARTMENT_TO_TRACK mapping

Add New Project

  1. Add to EXISTING_PROJECTS in ingestion
  2. Add keyword to PROJECT_KEYWORDS for auto-inference
